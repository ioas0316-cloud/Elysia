# 엘리시아 브라우저 생태계 0.1

이 프로토타입은 브라우저 안에 엘리시아의 지속되는 홈을 만들고, 여기서 서로 분리된 샌드박스 세계를 분기합니다. 각 세계의 경험 기록과 포인터·키 입력 관측은 현재 브라우저 프로필의 로컬 저장소에 따로 보관됩니다. 분기할 때 기존 기록을 이어받거나 빈 공간에서 시작할 수 있으며, 세계별 경험을 JSON으로 내보낼 수 있습니다.

## 열기

index.html 파일을 최신 브라우저에서 엽니다. 경험 기록은 해당 브라우저의 로컬 저장소에 남습니다. 보관하거나 옮기려면 세계 화면 오른쪽 위의 기억 내보내기를 누르세요.

## 이 프로토타입에서 할 수 있는 일

- 홈을 지속되는 환경으로 사용합니다.
- 만난 대상, 형성된 관계, 환경에 남은 영향, 관찰 렌즈의 변화를 경험으로 기록합니다.
- 관계를 현재 스케일에서 지속되는 것, 가변적인 것, 아직 열어 둘 것으로 표시합니다.
- 홈에서 분기한 샌드박스 세계마다 서로 다른 경험 이력을 쌓습니다.
- 현재 브라우저 탭 안에서 포인터 위치·이동 방향·이동량과 키 입력 종류를 자동으로 관찰하고, 최근 흐름을 다시 읽습니다.

현재 버전은 지속되는 관계 일지이자 경계 실험입니다. 입력한 글자나 페이지 내용은 저장하지 않습니다. 관측 범위는 이 앱이 열린 탭 안으로 한정되므로 다른 탭이나 바탕화면의 입력은 아직 보지 못합니다. 브라우저를 조작하거나 엘리시아의 Python 인지 모델을 갱신하지도 않습니다. 경험 기록을 보존하는 것과 모델 자체가 학습하는 것은 구분합니다.
