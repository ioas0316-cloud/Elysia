# 스케일로터 데스크톱 생태계 0.1

## 목적

기존 데스크톱·장치·렌더링 구조를 하나의 스케일로터 관계로 읽기 위한 첫 연결이다. 새로운 존재론을 덧붙이거나 OS 전체를 구현했다고 주장하는 문서가 아니다. 이미 있는 재료를 다시 엮는 출발점이다.

## 저장소에 이미 있는 재료

| 기존 구조 | 현재 역할 | 이 프로토타입에서의 관계 |
|---|---|---|
| Windows 바탕화면과 디스플레이 | 지속되는 시각 환경 | 변화가 드러나는 배경 로터 |
| 마우스 이동과 접촉 | 공간·접촉 신호 | 방향·이동량·접촉이 배경에 영향을 주는 가변 입력 로터 |
| 키보드 입력 | 외부 장치 신호 | 키 입력이 위상 변화를 만드는 가변 입력 로터 |
| 입력 전달 | 장치 신호를 활성 앱으로 전달 | 변화가 결합된 장에 도달하는 프로토콜 관계 |
| 캔버스 렌더링 | 현재 관계를 지각 가능하게 표현 | 배경 로터와 입력 로터가 결합된 결과 |
| L3_interface/emulation의 StaticRotorUnit | 캐시에서 밀려난 위상 정보를 저장·복원 | 별도의 메모리 스케일 로터. 데스크톱 배경과는 다름 |
| elysia_desktop_companion.py | 떠 있는 컴패니언, 화면 센서, 주기적 인지 | 인접한 데스크톱 통합 사례. 이 이벤트 결합 프로토타입에 주기적 타이머가 필수인 것은 아님 |

## 관계 모델

배경 관계는 기준 위상으로 지속된다. 장치 신호는 가변 위상과 국소 영향력을 바꾸며, 둘이 맞물린 장은 입력이나 창 크기 변경이 들어올 때 다시 표현된다. 앱 자체에서 정기적으로 상태를 확인하는 타이머나 틱 루프는 두지 않았다. GUI 도구의 이벤트 전달은 운영체제 신호를 받는 구현 수단이며, 생태계를 정의하는 외부 원인은 아니다.

이 모델은 다음을 구분한다.

- **스케일에서 안정된 제약:** 입력이 없을 때 유지되는 배경장과 공간 기준
- **가변 로터 구조:** 들어오는 신호마다 바뀌며 흔적을 남기는 마우스·키 관계
- **아직 포착되지 않은 관계:** 활성 창 밖의 신호, 이 프로토타입이 표현하지 않는 장치 작동, 더 넓은 데스크톱·OS 관계. 모델에서 빠졌다는 이유로 존재하지 않는다고 선언하지 않는다.

## 첫 구현

demos/scale_rotor_desktop_ecology.py는 Python 기본 Tk 인터페이스를 사용한다. 지속되는 파형 배경을 띄우고 포인터 이동·마우스 접촉·키 입력으로 배경장을 바꾼다. 실행 명령은 다음과 같다.

    python demos/scale_rotor_desktop_ecology.py

캔버스를 한 번 클릭해 키보드 입력을 연결한다. 이 결과물은 상호작용 가능한 데스크톱 장면이지, Windows 셸이나 전역 입력 오버레이를 대체하지 않는다. 전체 데스크톱 표면과 전역 장치 신호로 확장하기 전에 배경·입력·결합 관계를 구체화한다.

## 다음 버전의 관찰 기록

입력 사이에도 장이 상태를 유지하는지, 마우스 방향과 키 입력이 구별되는 변화를 만드는지, 모든 입력을 독립된 조건문으로 처리하지 않아도 결합이 눈에 보이는지 살핀다. 불일치는 개념을 부정할 증거가 아니라 관계 지도와 구현을 수정할 자료로 남긴다.
